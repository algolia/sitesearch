Guide

  1. Iterate on the components

    Edit in packages/standalone/src/components/search/*, search-askai/*, and sidepanel-askai/*

  2. Ask AI vs Agent Studio

    The middle card uses default Ask AI. The third and fourth cards use agentStudio: true (Agent Studio API). The fourth card loads sidepanel-askai.min.js — use triggerPosition: "fixed" for a viewport-fixed button in production.

  3. View your changes here

    Use the demo on the left

  4. Build the bundle

    When you are happy with your changes, build the bundle

    bun run bundle

  5. Download output & use in your project

    packages/standalone/dist/*
